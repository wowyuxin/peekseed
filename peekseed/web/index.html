How this works

Three steps, all under your data root.

  1. Add a link. Point peekseed at an embedding model, and optionally a reranker and an answer model.
  2. Add a dataset. Upload one or more PDFs in Datasets, then build a vector index with your embedding link.
  3. Search and ask. Every result links to its PDF page; send the sections you pick to an answer model and cite each as [n].

Service token (PEEKSEED_TOKEN)

This is the local service access token, generated in deploy/env/peekseed.env — not a model-provider API key. It is required for search, ask, uploads and link changes. Paste it once; it is kept only in this browser. You can also open the page as /#token=… to store it in one step.
